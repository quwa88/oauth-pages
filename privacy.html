プライバシーポリシー（plaude-notion）

最終更新：2026年10月4日

利用者

本アプリは開発者本人のみが、本人の Google アカウントで利用します。第三者の利用は想定していません。

取得する情報と用途

Google ドライブ API を通じて、本人が録音した音声ファイルを本人の Google ドライブの所定フォルダ（PLAUD）へ保存し、その共有リンクを本人の Notion に記録します。それ以外のファイルの読み取り・変更・削除は行いません。

保存と第三者提供

認可情報（トークン）は本人の PC 上にのみ保存します。Google ユーザーデータを第三者に提供・販売することはなく、広告に利用することもありません。

Google API Services User Data Policy

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含め、Google API Services User Data Policy に準拠します。

English summary

This app is used solely by its developer with their own Google account. It uses the Google Drive API only to upload the developer's own audio recordings into a designated folder in their own Drive and to record the resulting links in their own Notion workspace. Tokens are stored only on the developer's PC. No Google user data is shared, sold, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
